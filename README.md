## ✨ 核心特性一览

### 1. 🗺️ 全景视听无限画布 (Infinite Storyboard Canvas)
- **自由视界排布**：无边界画板自由缩放拖拽，角色卡、道具卡、场景卡与分镜节点以脉络图（Node Graph）形式自由连接。
- **直观视听比对**：支持多机位正反打对比、多版本画面实时比对与批量生成管理。
- **资产穿透引用**：在画布任意分镜节点一键拉取角色与场景参考图，免去手动上传。

### 2. 🎬 工业级导演级分镜引擎 (Director Agent Skills)
- **15 秒工业弹性分镜体系**：单条独立视频锁定 15 秒，弹性切分 5~6 镜，拒绝机械三段式。高燃动作 2~3 秒快切，对话重情绪 3~4 秒稳切。
- **独创防张冠李戴语法**：
  - `【空间绝对坐标与面部朝向】`：画死角色在画面的绝对横向坐标（左1/3、居中、右1/3）与景深层级（前景/中景/后景）。
  - `【唯一说话人与口型锁】`：严格限定每镜只允许一人动嘴，副角色闭嘴观望；内心独白强制锁死闭口。
  - `【分秒阶梯精准字数硬控】`：2秒 $\le 6$ 字，3秒 $\le 9$ 字，4秒 $\le 12$ 字，彻底杜绝视频模型吞字、怪叫与乱码。

### 3. 🥋 玄幻修仙与现代打斗动力学（袁洪 vs 玉鼎黄金骨架）
- 内置深度优化的 **玄幻仙侠打斗导演技能包** 与 **MiniMax H3 / Seedance 2.5 专用指令集**。
- 精准控制：起手交锋 → 接触瞬间 Hit-Stop（0.2s 物理定格） → 能量具象化扩散 → 冲击波反冲后坐力 → 终态物理抛飞隔离。

### 4. ⚡ 双轨制生成体系与高可用热备
- **官方云端免配置通道**：接入官方超清无水印生图与 3D 国漫大片视频引擎，开箱即用，按需结算，失败全额原路退还。
- **自定义第三方商业 API (BYOK)**：同时完美支持自由接入火山方舟（ByteDance）、可灵（Kling）、即梦（Dreamina）、MiniMax、Agnes、ComfyUI 等第三方商用接口。

## 🛠️ 工业级分镜提示词标准范例

```markdown
【镜头任务】：二郎真君神锋出鞘，三尖两刃枪与截教法宝虚空撞击。
【参考图深度绑定映射】：
- @图片1：【场景 - 昆仑断壁】对应全景断崖绝壁与漫射天光。
- @图片2：【角色 - 杨戬】对应画面居中偏左挺拔战神，面容冷峻。
【空间站位】：画面内共计1人，严格1人，无他人，全员男性。杨戬立于画面左侧1/3中景，正面偏右30度对峙。
【动态精密时间轴】：
- [0.0s-1.2s 起手交锋]：杨戬右手单握三尖两刃枪斜向右上方笔直刺出，枪尖破空带出青蓝锐利弧光；
- [1.2s-1.4s 接触核心]：枪尖与迎面袭来的黑煞魔光发生极限物理撞击，触发 0.2 秒 Hit-Stop 物理停顿；
- [1.4s-3.0s 力量爆发]：刺目白金电浆呈环形向外狂暴震荡，强劲气浪将漫天碎石与微尘沿法线方向反冲轰飞。
【唯一说话人口型锁】：杨戬嘴部紧闭，神情坚毅冷肃，全程无开口动作。
【动作音效】：金属交鸣高频震颤声，剧烈气浪音爆爆裂声。
【强制禁止项】：禁止画面变形，禁止多余角色，禁止字幕，禁止多余肢体。
```
