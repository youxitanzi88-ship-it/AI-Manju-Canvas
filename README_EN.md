## 🌟 Overview

**HuojuHou (Hjh-Manju)** is an all-in-one industrial AIGC production studio tailored for creators of **AI short dramas, motion comics (Manju), novel promotion videos, and cinematic shorts**. 

It eliminates the fragmented "single-prompt slot machine" workflow by unifying **Infinite Canvas visual orchestration** with **Cinematic Director Agent Skills**. The system seamlessly connects every stage: **Novel script parsing → Character/Scene asset locking → 15-second dynamic multi-beat storyboarding → Kinetic combat prompt generation → One-click video synthesis**.

---

## ⚡ Key Highlights

- **🗺️ Infinite Storyboard Canvas**: Free-form 2D workspace with node-based connections for script beats, character asset sheets, multi-angle camera shots, and video generation cards.
- **🎬 Anti-Hallucination Cinematic Framework**:
  - `SPATIAL-GRID Locking`: Explicit horizontal coordinates (left 1/3, center, right 1/3) and depth layers (foreground/midground/background) to avoid cross-character attribute mixing.
  - `Dialogue Speaker Lip-Sync Lock`: Strict single-speaker mouth movement with zero mouth action for off-screen internal monologues.
  - `Step-Precision Word Limits`: Strict word budget per second ($\le 6$ words for 2s, $\le 9$ words for 3s) eliminating model sound artifacts and garbled speech.
- **🥋 R3 Kinetic Combat Dynamics (Hit-Stop Physics)**:
  - 0.2s physical freeze frame (Hit-Stop) upon critical impact.
  - Plasma/energy shockwave vector propagation with authentic recoil dynamics.
- **🔌 Multi-Engine Integration**:
  - Official zero-config high-speed cloud gateway (Seedance 2.5, MiniMax H3, ByteDance Ark).
  - Full BYOK (Bring Your Own Key) compatibility for Kling AI, Dreamina, Agnes, and ComfyUI.
