# 🎬 火剧猴 (Hjh-Manju) · S级漫剧工业分镜提示词工程规范

## 一、核心原则

1. **废除机械平分**：彻底摒弃死板平分（0-3秒、3-7秒、7-10秒）的三段式切分，全面采用**真实因果律时间轴**。
2. **15秒单条视频弹性切分（5~6镜）**：
   - 动作打斗/快节奏：多用 2~3 秒短镜头；
   - 情绪对话：多用 3~4 秒近景与特写；
   - 纯动作无台词镜头：严格不超过 3 秒。
3. **分秒阶梯精准字数硬控刻度表**：
   - 2 秒镜头：台词 $\le 6$ 字（独白 $\le 8$ 字）
   - 3 秒镜头：台词 $\le 9$ 字（独白 $\le 12$ 字）
   - 4 秒镜头：台词 $\le 12$ 字（独白 $\le 16$ 字）
   - *超长台词必须拆成连续正反打镜头并切换景别。*

## 二、防张冠李戴与防口型穿帮铁律 (ANTI-HALLUCINATION LOCK)

### 1. 空间绝对坐标与面部朝向 (SPATIAL-GRID)
每个分镜必须写死角色在画面的绝对横向坐标（左1/3、居中、右1/3）、纵深景深层级（前景/中景/后景）与面部朝向角度：
> 示例：`画面内共计2人，严格2人，无他人。左为A右为B，A立于画面左侧1/3中景侧身45度，B立于右侧1/3近景正面迎击，严禁调换角色位置。`

### 2. 唯一说话人与口型锁 (DIALOGUE-SPEAKER-LOCK)
- 每镜台词只允许一人开口说话：
  `【当前唯一开口说话人】：角色A（在场其他角色保持闭嘴沉默、肃立观望或防御姿态，严禁副角色动嘴，严禁双人同说）`
- 内心独白画外音锁：
  `角色A内心独白：“……”（内心独白无口型，是画外音，嘴部无任何开口动作）`

## 三、R3 玄幻与仙侠打戏动力学 (Hit-Stop 物理顿挫)

- **起手交锋**：动作起动矢量明确，发力肢体与位移轨迹具象化；
- **接触核心**：在关键碰撞与法宝撞击瞬间，触发 **0.2~0.3 秒 Hit-Stop 极限物理停顿**；
- **力量爆发**：冲击波沿接触面法线方向扩散，反冲力与物理抛飞轨迹明确；
- **终结收束**：执行受力隔离，维持终态稳定。
